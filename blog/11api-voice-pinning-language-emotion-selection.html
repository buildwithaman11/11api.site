I Added Voice Pinning, Language & Emotion Selection to 11API

By Aman

Hi, my name is Aman. I am a BCA student, and 11API is my side project.

I built 11API because I wanted to use ElevenLabs and Gemini TTS in one place to create voiceovers for my videos. I don't really like using my own voice for videos, so I wanted a simple way to create AI voiceovers and use them with my videos.

I am building 11API step by step, and whenever I add something new, I want to share what I added and how it works here.

New features added today

Today, 21 September 2026, I added three new features to the 11API voice selection system.

1. Pin your favorite voices

You can now pin or mark any voice you like.

If you find a voice that you want to use again later, you can pin it so you can find it more easily instead of searching through all the available voices again.

2. Select the language for your voiceover

You can now select the language you want to generate your voiceover in.

This makes it easier to find and use voices for different languages instead of having to search through every voice manually.

3. Select the emotion of the voice

You can also now select the emotion you want for your voiceover.

Depending on the type of video I'm making, I might want a voice that sounds different, so I wanted to make it easier to choose a voice based on the emotion I need.

Why I added these features

When I was using AI voice tools myself, I noticed that finding the right voice could take more time than I wanted.

I wanted 11API to make that process simpler.

Now I can find a voice, pin the ones I like, choose the language, and select the type of emotion I want before creating the voiceover.

This is a small update, but I think it makes the voice selection process much easier.

I'll keep improving 11API as I use it myself and find things that could be better.

More updates coming soon.
