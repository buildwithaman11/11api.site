11API — WEBSITE FILES & UPLOAD INSTRUCTIONS
=============================================

This folder is a complete, ready-to-upload copy of your entire site —
the tool, the blog, and every supporting SEO/AdSense file. Everything
in here is current as of Sep 20, 2026, including the new footer that
now appears on EVERY page with:

  - Facebook, Instagram, TikTok, and Email icons (glow their brand
    colour on hover)
  - Your contact email, shown as visible text
  - Navigation links (Blog / About / Privacy Policy)

This footer/contact update satisfies Google AdSense's requirement
that visitors can find a way to contact you on every page of the site.

HOW TO UPLOAD THIS — STEP BY STEP
------------------------------------

1. Go to github.com and open your repository (the one connected to
   11api.site).

2. Click "Add file" -> "Upload files".

3. Drag in these 8 files ALL AT ONCE, into the repo's ROOT (top
   level — not inside any subfolder):

     index.html
     about.html
     privacy.html
     robots.txt
     sitemap.xml
     CNAME
     .nojekyll
     og-image.png

   GitHub will say these already exist and will be REPLACED — that's
   correct, let it overwrite them.

   NOTE: ".nojekyll" starts with a dot, so it may be hidden on your
   computer. Turn on "show hidden files" in your file explorer if
   you don't see it, to make sure it actually gets uploaded.

4. Commit with a message like "Add contact footer + social links".

5. Now upload the blog folder. Click "Add file" -> "Upload files"
   again, and drag in the whole "blog" folder from this download —
   GitHub recreates the folder structure automatically. If your
   browser only accepts individual files, type "blog/" at the start
   of the path for each of these three, one at a time:

     blog/blog.css
     blog/index.html
     blog/how-to-write-natural-sounding-voiceover-scripts.html

6. Commit that too.

7. Wait about a minute, then check every page loads AND scroll to
   the bottom of each one to confirm the new footer with social
   icons appears:

     https://11api.site/
     https://11api.site/about.html
     https://11api.site/privacy.html
     https://11api.site/blog/
     https://11api.site/blog/how-to-write-natural-sounding-voiceover-scripts.html

8. Hover over each social icon in the footer — Facebook should glow
   blue, Instagram pink, TikTok cyan/pink, and the mail icon red.
   Click each one to confirm it opens the right profile / email app.


IF SOMETHING LOOKS WRONG
---------------------------

- Page shows old content -> hard-refresh (Ctrl+Shift+R / Cmd+Shift+R)
  since GitHub Pages and your browser can both cache the old version
  for a minute or two.
- Icons show as plain unstyled links or broken -> confirm blog/blog.css
  uploaded correctly (about.html and privacy.html both depend on it).
- A page 404s -> check it's in the right folder and the filename is
  exactly right, including lowercase letters.
